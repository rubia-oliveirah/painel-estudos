# 🔐 Painel de Estudos de Cibersegurança

## 🎯 Objetivo do projeto

Este projeto tem como objetivo desenvolver uma aplicação web simples para auxiliar na organização e no acompanhamento dos estudos na área de **Cibersegurança**.

A aplicação permitirá registrar assuntos estudados, acompanhar o progresso e organizar os conteúdos de acordo com as áreas de interesse.

O projeto foi desenvolvido como atividade acadêmica do curso de **Sistemas de Informação**, com o objetivo de aplicar conhecimentos de desenvolvimento web e programação.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

### Tecnologias que poderão ser utilizadas futuramente

* LocalStorage
* React
* Node.js

## 📋 Funcionalidades

* Cadastro de assuntos para estudo
* Marcação de assuntos como concluídos
* Visualização do progresso dos estudos
* Organização dos conteúdos por categorias
* Armazenamento das informações no navegador

## 📚 O que foi aprendido

Durante o desenvolvimento do projeto, foram praticados e consolidados conhecimentos relacionados a:

* Estruturação de páginas utilizando HTML;
* Estilização de interfaces com CSS;
* Programação utilizando JavaScript;
* Manipulação do DOM;
* Utilização de eventos para criar interatividade;
* Organização de código;
* Utilização do Git para controle de versões;
* Criação e gerenciamento de repositórios no GitHub;
* Documentação de projetos utilizando Markdown.

Além dos conhecimentos técnicos, o projeto possibilitou compreender a importância de organizar e documentar uma aplicação para facilitar sua compreensão e manutenção.

## 🚀 Próximos passos

Como evolução do projeto, pretende-se adicionar novas funcionalidades, como:

* Sistema de categorias;
* Indicador de progresso;
* Melhorias na interface;
* Integração com um banco de dados;
* Autenticação de usuários;
* Novas funcionalidades relacionadas à organização dos estudos.
